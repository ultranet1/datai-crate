# datai-crate
A unified end-to-end Data &amp; AI platform, for Big Data Analytics, Engineering &amp; Machine Learning.


 It is simply an open-source form of Databrick, with 2 interface.
## A. Beginner interface ( drag & drop UI) for non-technical users
## B. Expert interface ( more modification) notebook with 3 programming languages for technical users ( Python, SQL, Linux)



## A. In Beginner mode: DataI-Crate presents a complete data and AI architecture with 5 main components:
1.Data Collection
   - Web Scraping
   - APIs
   - IoT Devices
   - External Data Sources
2.Data Processing
   - Data Ingestion
   - Data Cleaning & Transformation
   - ETL Pipelines
3.Data Storage
   - Data Warehouse
   - Data Lake
   - Unified Data Platform
4.Analytics & BI
   - Reporting Dashboards
   - Data Visualization
5.AI & Machine Learning
   - Model Deployment
   - Intelligent Insights & Decisions

## B.  Expert mode: Data-crate provides more flexible and professional options, with the 7 major interface of databricks:
1. Notebooks:
- Python
- SQL
- Bash
2. SQL Editor (with different flavors)
- PostgreSQL
- SQL server
3. Catalogs:
- Tables
- Folders
- Files
4.  Compute, for:
- ML notebooks
- Analytics
- Processing
5. Workflows for: 
- automating, 
- monitoring, 
- tasks and data pipelines
6. Dashboards for creating 
- reports, 
- charts, 
- metrics & 
- kpis
7. Model serving endpoint, for:
- training
- feature engineering
